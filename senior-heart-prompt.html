프롬프트 생성기

아이디어가 없어도 랜덤으로 소재를 뽑고, OpenAI API로 바로 쇼츠 대사·이미지 프롬프트·영상 프롬프트·SRT를 생성합니다. 결과 이미지 프롬프트는 실사 대신 Pixar-inspired 3D와 옛날 한국 감성을 기본으로 만듭니다.

기능
  • 모델 선택
  • 랜덤 조합 만들기
  • AI 랜덤 아이디어 받기
  • API 연결 테스트
  • 결과 복사 / 다운로드

설정

개인용 정적 페이지 방식입니다. 공개 서비스로 운영할 땐 서버 프록시를 사용하세요.
기본 추천은 gpt-5.5입니다. 비용/속도가 중요하면 mini/nano 계열을 선택하세요.
