부모님 속마음
프롬프트 생성기

오브젝트와 배경을 직접 넣거나 AI 추천으로 뽑고, 부모님 세대의 말하지 못한 마음을 자연스럽게 이어지는 쇼츠 대사로 만듭니다. 이미지/영상 프롬프트는 실사 대신 픽사풍 3D와 옛날 한국 감성을 기본으로 생성합니다.

기능
  • 오브젝트/배경 AI 추천
  • 직접 키워드 추가
  • 모델 선택
  • API 연결 테스트
  • 결과 복사 / 다운로드

설정

개인용 정적 페이지 방식입니다. 공개 서비스로 운영할 땐 서버 프록시를 사용하세요.
기본 추천은 gpt-5.5입니다. 모델명이 다르면 직접 입력을 선택하세요.
AI 추천을 누르면 오브젝트 후보가 추가됩니다. 직접 적고 +를 누르면 내 키워드로 추가됩니다.
AI 추천을 누르면 배경 후보가 추가됩니다. 직접 적고 +를 누르면 내 장소로 추가됩니다.

생성 결과

왼쪽 설정을 채우고 생성 버튼을 눌러주세요.

GitHub Pages에 이 파일을 senior-heart-prompt.html로 올리면 바로 사용할 수 있습니다.
